# C++ Journal

My code and notes while learning C++.

Each folder in `entries/` is one topic: `main.cpp` (the code) and `notes.md` (what I learned).

## Workflow

```powershell
.\new "pointers"    # start a new entry (creates the folder, opens it in VS Code)
                    # Ctrl+Shift+B builds & runs the open .cpp file
.\save "message"    # commit + push to GitHub (message is optional)
```
